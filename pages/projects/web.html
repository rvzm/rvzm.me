This Site

A single HTML shell, a hash router, and no build step — the simplest thing that could plausibly need a router.

Where it stands

Live and actively worked on. Pages are plain HTML fragments swapped in by the router, config lives in one file, and the sidebar pulls live commit/branch activity straight from the GitHub API.

How this site is built

Bootstrap 5 for layout, one shell page, and a hash router that swaps in page fragments. No build step and no framework.

Some bits are imported, such as:

  • Bootstrap
  • Rapsssito/github-profile-badge
  • Discord widget
  • GitHub/public-apis

The Idea

Keep it simple. No framework, no build step, no server-side code. Just a single HTML shell that swaps in page fragments and a sidebar that talks to the GitHub API directly from the browser. The sidebar is a live read of what I pushed most recently, and the pages are just static HTML fragments.

I've made it so pages are loaded dynamically via the hash router, ensuring that only the necessary content is fetched and displayed, while also making adding content easy without needing to touch the main shell.
