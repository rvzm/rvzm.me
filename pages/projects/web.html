rvzm.me

This site. A single HTML shell, a hash router, and no build step — the simplest thing that could plausibly need a router.

Where it stands

Live and actively worked on. Pages are plain HTML fragments swapped in by the router, config lives in one file, and the sidebar pulls live commit/branch activity straight from the GitHub API. See the about page for how it's built.

Notes

Source is at rvzm/rvzm.me — also tracked in the sidebar. Runs on kelvin, same as homelab.
